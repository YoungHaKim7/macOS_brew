# macOS 영문판에서 시각 효과(애니메이션 및 투명도)를 꺼서 시스템 속도를 높이거나 눈의 피로를 줄이려면 Accessibility(손쉬운 사용) 설정을 변경해야 합니다.
다음 단계를 따라하시면 됩니다.

⚙️ 시각 효과 끄기 단계

- 1. 화면 왼쪽 상단의 Apple 메뉴()를 클릭한 뒤 System Settings...(또는 구형 macOS의 경우 System Preferences...)를 선택합니다.
- 2. 왼쪽 사이드바에서 Accessibility를 클릭합니다.
- 3. 오른쪽 항목 중 Display를 선택합니다.
- 4. 다음 두 가지 옵션을 켜서 활성화합니다.
    -  • Reduce motion: 창이 열리거나 닫힐 때, 화면이 전환될 때의 애니메이션 효과를 줄입니다.
    -  • Reduce transparency: 창 배경이나 바(Bar)의 반투명 효과를 제거하여 불투명하게 만듭니다.

## 💡 추가로 설정을 변경하면 좋은 항목 (Dock 애니메이션)

- Dock바가 사라지거나 나타날 때의 애니메이션도 끄고 싶다면 아래 설정을 추가로 변경해 보세요.
  - 1. System Settings에서 Desktop & Dock으로 이동합니다.
  - 2. Animate opening applications 옵션을 끕니다(체크 해제).
  - 3. Minimize windows using 옵션을 Genie effect에서 Scale effect로 변경합니다. (크기 축소 효과가 메모리를 덜 차지하고 더 빠릅니다.)
